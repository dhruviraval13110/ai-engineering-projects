# Contributing

This repository is primarily a learning portfolio, but improvements should still follow engineering discipline.

## Pull requests

Include:
- problem statement;
- change summary;
- tests;
- documentation changes;
- known limitations.

## Code

Prefer:
- small functions;
- type hints;
- explicit validation;
- deterministic behavior;
- tests for important behavior.

Avoid:
- secrets;
- unexplained magic numbers;
- copied tutorial code;
- fake benchmark claims.
